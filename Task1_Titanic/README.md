# Titanic Survival Prediction

This project predicts whether a passenger survived the Titanic disaster using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Algorithm
- Logistic Regression

## Features Used
- Age
- Gender
- Passenger Class
- Fare
- SibSp
- Parch

## Outcome
Prediction of passenger survival.
