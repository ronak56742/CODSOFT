# Iris Flower Classification

This project classifies iris flowers into different species using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Algorithm
- Logistic Regression

## Features Used
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Goal
Predict iris flower species accurately.
